valenced plugins

includes all of my valenced plugins:

"more fonts" (3 font packs: "Figtree", "IBM Plex Mono", and "OpenDyslexic"); "Rosé Pine" (3 themes: "Rosé Pine", "Rosé Pine Moon", and "Rosé Pine Dawn", and 1 icon pack: "Rosé Pine"); as well as "more palettes" (2 themes: "more purple" and "more blue").
how to install:

  1. copy the link listed below
  2. open valenced and navigate to Settings > Plugins > Advanced (the cog icon in the top right corner)
  3. paste the link you copied into the Repository URL field, and tap Add Repository
  4. navigate to Settings > Themes > Manage theme plugins > Browse Themes (the plus icon in the bottom right)
  5. tap install next to any desired plugins
  6. enable installed plugins at: Settings > Themes > Manage theme plugins
  7. select themes, font packs, and icon packs from enabled plugins at: Settings > Themes > Colors / Fonts / Icons

install link: https://caramel3625.github.io/valenced-plugins/

Rosé Pine for Revenge/ShiggyCord/Kettu:

All natural pine, faux fur and a bit of soho vibes for the classy minimalist. Includes all three Rosé Pine variations: Rosé Pine, Rosé Pine Moon, and Rosé Pine Dawn.

How to install:

  1. Copy the link corresponding to the theme variant you're trying to install
  2. Open Revenge, ShiggyCord, or Kettu
  3. Navigate to Settings > Themes > Add Theme (the plus icon in the bottom right corner)
  4. Paste the link you copied, and tap Install
  5. Select the theme variant you installed from the list of themes

Rosé Pine: https://raw.githubusercontent.com/caramel3625/rose-pine-for-discord-mobile/refs/heads/main/dist/rose-pine.json
Rosé Pine Moon: https://raw.githubusercontent.com/caramel3625/rose-pine-for-discord-mobile/refs/heads/main/dist/rose-pine-moon.json
Rosé Pine Dawn: https://raw.githubusercontent.com/caramel3625/rose-pine-for-discord-mobile/refs/heads/main/dist/rose-pine-dawn.json
